# Quickstart

1. Check the Python version:

   ```sh
   python3 --version
   ```

2. Clone this repository:

   ```sh
   git clone https://github.com/CryptoZephyr/elsewhere.git elsewhere-checkout
   ```

3. Enter the sample directory:

   ```sh
   cd elsewhere-checkout/sample
   ```

4. Run the greeting command:

   ```sh
   python3 hello.py greet Ada
   ```

Expected output:

```text
hello Ada
```
